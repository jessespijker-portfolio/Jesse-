Pill-knop; primary (ink) voor de hoofd-CTA, accent (oranje) hooguit 1x per view, ghost voor secundair.

```jsx
<Button variant="primary" arrow href="#projecten">Bekijk projecten</Button>
<Button variant="ghost" size="sm">Meer over mij</Button>
```

Props: variant, size (sm/md/lg), arrow (→ schuift op hover), href maakt er een link van.
